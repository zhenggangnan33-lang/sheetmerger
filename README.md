# SheetMerger 多表汇总工具

把一个文件夹里格式不完全一致的多个表格（xlsx / xls / xlsb / csv）合并、清洗、汇总，
导出一个带"问题清单"的结果表。适合财务、运营、行政人员处理各门店 / 各部门上报的表格。

- **表头不一致也能合并**：自动识别"金额 / 金额(元) / 销售额"等同义表头，可手动确认，越用越准
- **脏数据不崩溃**：文本数字、各种日期写法、"无""/"等占位值自动处理；
  处理不了的值逐条列出，精确到 文件 / Sheet / 行号 / 列名
- **配置可保存**：下次同样的汇总一键重跑
- **全部在本机处理**：不联网、不上传，任何数据都不会离开你的电脑

---

## 一、安装

1. 系统要求：Windows 10 / 11（64 位）。不需要安装 Excel 或 WPS（查看结果时需要）。
2. 把 `SheetMerger_v1.0.0` 文件夹复制到任意位置，双击 `SheetMerger.exe` 即可运行，无需安装。
3. 首次打开需要 5–15 秒（程序在解压运行文件），之后会快一些。

> 如果出现"Windows 已保护你的电脑"：点"更多信息" → "仍要运行"。详见下方常见问题。

## 二、使用步骤

### 第 1 步：选择文件夹
1. 点"浏览…"，选择存放表格的文件夹（需要包含子文件夹里的文件时，勾选"包含子文件夹"）。
2. 程序列出识别到的所有文件和 Sheet：
   - 不需要汇总的 Sheet，取消勾选即可；
   - "表头行"是自动识别的表头所在行，如果不对，**双击数字直接修改**；
   - 打不开的文件（损坏、加密等）以红字显示原因，不影响其他文件。
3. 点"下一步"。

### 第 2 步：表头映射
每种不同的表头写法占一行，颜色表示识别结果：

| 颜色 | 状态 | 含义 |
|---|---|---|
| 绿 | 自动 | 已确定对应到标准列，无需处理 |
| 黄 | 待确认 | 比较像某个标准列，请确认 |
| 红 | 未匹配 | 没找到对应的标准列，默认按原表头保留 |
| 蓝 | 手动 | 你已确认或修改过 |
| 灰 | 忽略 | 不导出该列 |

- 在"映射到"中选择正确的列名，或直接输入新的列名；选"（忽略此列）"则不导出。
- "全部待确认按建议确认"可一次性确认所有黄色项。
- 确认过的映射会被记住，下次遇到同样的表头自动识别。

### 第 3 步：汇总设置
- **分组列**：按什么分类汇总，如"门店"；可多选（如 门店 + 商品），可拖动调整顺序。
- **汇总列**：要统计的列及方式（求和 / 计数 / 平均 / 最大 / 最小），可添加多行。
- **重复记录**：
  - 只标记重复（默认）：重复记录列入问题清单，但仍参与汇总；
  - 删除重复：只保留第一次出现的记录；
  - 判断依据：不勾选表示所有列都相同才算重复，也可只按"单号"等关键列判断。
- **输出**：保存位置（默认与输入文件夹相同）和文件名（默认 `汇总结果_年月日_时分秒.xlsx`）。

### 第 4 步：运行
点"开始运行"，可随时"取消"。完成后显示处理的文件数、行数和问题数，
可直接"打开结果文件"或"打开所在文件夹"。

### 保存配置，下次一键运行
- 设置好后点工具栏"保存配置"，得到一个 `.json` 文件。
- 下次点"加载配置"选择这个文件，再点"**一键运行**"即可直接生成结果；也可以逐步检查后再运行。

## 三、结果文件说明

一个 xlsx 文件，三个 Sheet：

| Sheet | 内容 |
|---|---|
| 汇总 | 分组列 + 各汇总列 + 记录数，最后一行为"总计" |
| 明细 | 合并后的全部记录；最后三列"来源文件 / 来源Sheet / 原始行号"可追溯到原表 |
| 问题清单 | 按 错误 > 警告 > 提示 排序，每条带 文件 / Sheet / 行号 / 列名 / 原始值 / 说明 |

- **错误**：值无法转换（在明细中留空，不计入汇总）、文件打不开等，**需要处理**。
- **警告**：待确认的表头、重复记录、空文件等，建议检查。
- **提示**：跳过的合计行、标题行、缺少的列等，一般无需处理。

## 四、自动处理规则

- 跳过 `~$` 开头的 Excel 临时文件、隐藏文件，以及本工具生成的 `汇总结果_*.xlsx`
- 表头：前 20 行中文字内容最多的一行；上方的大标题、"单位：元"等行自动跳过
- 跳过：空行、首列含"合计 / 总计 / 小计"的行、只有一个文字单元格的说明行（如"制表人：张三"）
- 合并单元格：自动把合并的值填到每一行
- 数字：去掉千分位逗号、"元"、¥、空格；支持全角数字、`(26.00)` 会计负数、百分比
- 视为空值：无、/、-、—、N/A、空白
- 日期：2026-10-02、2026/10/2、2026.10.2、20261002、2026年10月2日、Excel 日期序列号
- Excel 错误值（#DIV/0!、#N/A 等）记为错误，不当作空值
- CSV 编码自动识别（UTF-8、UTF-8-BOM、GBK 等）

## 五、常见问题

**双击后很久没反应？**
首次启动需要 5–15 秒解压运行文件，请稍等，不要重复双击。

**提示"Windows 已保护你的电脑"或被杀毒软件拦截？**
这是未做数字签名的新程序常见的提示，点"更多信息" → "仍要运行"；
杀毒软件拦截时，可把 `SheetMerger.exe` 加入信任列表。本程序不联网、不修改系统。

**结果文件保存失败？**
同名的结果文件可能正在 Excel / WPS 中打开，请关闭后重试，或换一个文件名。

**某个文件没有被汇总？**
看第 1 步列表中该文件的状态，或结果文件"问题清单"里的说明。
常见原因：文件损坏、设置了打开密码（请先去掉密码）、Sheet 没有勾选、Sheet 里没有能识别的列。

**表头识别错了 / 标题行被当成了数据？**
在第 1 步双击"表头行"改成正确的行号。

**列对应错了？**
在第 2 步修改"映射到"。修改会被记住；如果想清空所有记住的映射，删除
`%APPDATA%\SheetMerger\aliases.json` 即可（在资源管理器地址栏输入 `%APPDATA%\SheetMerger` 打开）。

**汇总金额比预期少？**
查看问题清单中"数值无法转换"的错误——这些单元格的值无法识别，没有计入汇总。
在原表中修正后重新运行即可。

**重复记录的警告太多？**
默认要求所有列都相同才算重复。如果数据本身就可能有完全相同的正常记录，
在第 3 步把"判断依据"设为"单号"等能唯一标识一条记录的列，或选择"不检查重复"。

**CSV 打开是乱码？**
程序会自动识别编码。极少数情况下识别不准，可用记事本打开该 CSV，"另存为"时编码选 UTF-8 后再运行。

**数据量有限制吗？**
Excel 每个 Sheet 最多约 104 万行，明细超出时自动续到"明细_2"。
参考速度：50 个文件、每个 1 万行，约半分钟完成（视电脑性能而定）。

**WPS 能打开结果文件吗？**
可以。结果文件是标准 xlsx 格式，Microsoft Excel 和 WPS 均可打开。

**程序出错闪退怎么办？**
程序会弹出错误说明，并把详细信息保存到 `%APPDATA%\SheetMerger\logs\`，把该日志发给技术支持即可。

**我的数据安全吗？**
所有处理都在本机完成，程序没有任何联网、上传或统计功能。

## 六、命令行版（可选）

打包时可额外生成 `SheetMerger-cli.exe`，便于批量或定时处理；从源码运行时用 `python cli.py`。

```bash
# 按门店汇总金额
SheetMerger-cli --input 数据文件夹 --group 门店 --sum 金额 --output result.xlsx

# 多个分组列、多种汇总方式
SheetMerger-cli -i 数据文件夹 -g 门店,商品 -s 金额 -a 数量:平均 -a 日期:最大

# 只看识别出的表头和映射建议，不导出
SheetMerger-cli -i 数据文件夹 --show-mapping

# 使用界面中保存的配置文件运行（与界面结果一致）
SheetMerger-cli --config 我的任务.json
```

| 参数 | 说明 |
|---|---|
| `-r/--recursive` | 包含子文件夹 |
| `--dedup off/mark/drop` | 重复记录：不检查 / 只标记（默认）/ 删除 |
| `--dedup-cols 列1,列2` | 按指定列判断重复，默认按全部业务列 |
| `--map "原表头=目标列"` | 手动表头映射，目标留空表示忽略该列；加 `--learn` 写回别名字典 |
| `--header-row "文件|Sheet=行号"` | 手动指定表头行 |
| `--exclude "文件|Sheet"` | 排除某个 Sheet，`文件|*` 排除整个文件 |
| `--type 列名=number` | 指定列类型（text / number / date） |
| `--strict-mapping` | 不采用"待确认"的表头映射 |
| `--drop-unmatched` | 丢弃未匹配到标准列的列 |
| `--save-config 文件.json` | 保存本次配置 |

## 七、开发者说明

### 环境
Python 3.11（64 位）。

```bash
python -m pip install -r requirements.txt
python app.py                         # 图形界面
python cli.py --help                  # 命令行
```

### 目录结构

```
core/          读取、表头映射、清洗、校验、汇总、导出、流程编排（pipeline.py）
config/        任务配置保存 / 加载
gui/           分步向导界面（PySide6）
app.py         图形界面入口（打包主程序）
cli.py         命令行入口
tests/         测试、测试数据生成（generate_test_data.py）、性能测试（benchmark.py）
packaging/     打包配置（sheetmerger.spec）、Windows 打包脚本、版本信息、LGPL/GPL 许可文本
```

### 测试

```bash
python tests/generate_test_data.py    # 重新生成 tests/test_data（19 个脏数据样本）
python -m pytest                      # 界面测试在无显示器环境下自动使用 offscreen 模式
python tests/benchmark.py 50 10000    # 性能测试：50 个文件 × 1 万行
```

性能参考（Linux 云主机，50 万行）：读取 7 秒、清洗 4 秒、查重 3 秒、汇总 1 秒、写出 10 秒，
合计约 24 秒，结果文件约 31 MB，峰值内存约 700 MB。写出时先用 openpyxl 生成样式、列宽、
冻结窗格等骨架，再直接流式写数据行 XML（逐个创建 openpyxl 单元格对象在 50 万行时需 50 多秒）。

### 打包 Windows exe

**方式一：GitHub 自动打包（推荐）**

`.github/workflows/build-windows.yml` 会在 GitHub 的 Windows 服务器上自动测试并打包：

- 推送到 `main`、提交 PR，或在仓库 **Actions → Windows 打包 → Run workflow** 手动运行；
  完成后在该次运行页面底部的 **Artifacts** 中下载 `SheetMerger_v<版本号>_windows`
  （内含 `SheetMerger.exe`、`SheetMerger-cli.exe`、说明和许可文件），保留 30 天。
- 推送版本标签（如 `git tag v1.0.1 && git push origin v1.0.1`）时，另外自动创建
  GitHub Release 并附上发布包，长期保存。
- 流程：安装依赖 → 生成测试数据并跑全部测试 → PyInstaller 打包 →
  冒烟测试（命令行版完整跑一遍测试数据；图形界面版启动 20 秒不退出）→ 上传。

**方式二：在本机 Windows 上打包**

PyInstaller 不能跨平台生成 exe，必须在 Windows 上运行。

1. 安装 [Python 3.11 64 位](https://www.python.org/downloads/windows/)（勾选 "Add python.exe to PATH" 和 "py launcher"）。
2. 在项目目录运行：
   ```bat
   packaging\build_windows.bat          :: 只打图形界面版
   packaging\build_windows.bat cli      :: 同时打命令行版
   ```
   脚本会：创建独立虚拟环境 `.venv-build` → 安装依赖 → 生成测试数据并跑全部测试（不通过则停止）
   → PyInstaller 打包 → 冒烟测试 → 组装发布目录。
3. 发布目录 `dist\SheetMerger_v<版本号>\` 包含：
   `SheetMerger.exe`（单文件，约 80–110 MB）、`README.md`、`LICENSES.md`、`licenses\`（LGPL-3.0 / GPL-3.0 原文）。

其他说明：
- 版本号在 `core/__init__.py`，发布前同步修改 `packaging/version_info.txt`（exe 文件属性中显示）。
- 程序图标：`packaging/app.ico`（exe 图标）和 `gui/app_icon.png`（窗口图标）由
  `python packaging/make_icon.py` 生成；替换这两个文件即可更换图标。
- **建议做代码签名**（signtool + 代码签名证书），可大幅减少 SmartScreen 提示和杀毒软件误报。
- PySide6 为 LGPL-3.0：发布时必须附带 `licenses\` 目录和 `LICENSES.md`（打包脚本已自动复制）。
  单文件 exe 运行时会把 Qt 动态库解压为独立文件，用户可以替换；如需更稳妥，可改用
  PyInstaller 的目录模式（onedir）发布。

### 用户数据位置
- 别名字典：`%APPDATA%\SheetMerger\aliases.json`（Linux/macOS 为 `~/.sheetmerger/`）
- 错误日志：`%APPDATA%\SheetMerger\logs\`
- 可用环境变量 `SHEETMERGER_HOME` 改到其他位置（测试时使用）。
